# 嵌入式操作系统100问

> 大家好，我是李述铜。这个专栏用来解答嵌入式操作系统学习和开发中最常见的 100 个问题。

## 专栏简介

嵌入式操作系统（RTOS）是嵌入式开发的核心技能，但很多初学者在学习和使用过程中会遇到各种各样的疑问——

- 任务和函数到底有什么区别？
- 优先级高的任务一定先执行吗？
- 中断里为什么不能随便调阻塞接口？
- 消息队列和邮箱到底怎么选？
- 栈溢出是怎么发生的，怎么排查？

本专栏从实际开发场景出发，用通俗易懂的语言 + 代码示例，逐一解答这些高频问题。每篇文章聚焦一个问题，讲清楚原理和实战要点。
